# Source Security Assessment

Assessment date: 2026-09-02  
Scope: `src/` (OWASP Juice Shop 20.2.0)  
Method: static source review cross-checked against all 116 entries in `src/data/static/challenges.yml`

> **Warning:** This is an intentionally vulnerable training application. It must not be exposed to untrusted networks or used as a production application. The `infrastructure/` files are intentionally insecure and must not be deployed.

CVSS values below are CVSS v3.1 estimates from the checked-in default configuration, not vendor-issued scores. “Effect” states the principal security impact. `N/A` means the item is a training/discovery challenge rather than a security vulnerability in the running shop. Findings carrying a Docker/Heroku `disabledEnv` gate are disabled there by the default `challenges.safetyMode: auto`; they become reachable on an ordinary local deployment or when safety mode is disabled. Runtime exploitation was not performed because dependencies are not installed in this snapshot.

The complete server input-surface inventory is in [`endpoints.csv`](endpoints.csv). It contains 169 method/route or Socket.IO-event rows and explicitly records query strings, path parameters, headers/cookies, body fields, access requirements, and source locations.
